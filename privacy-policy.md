# Privacy Policy — Auto Confluence Documentation

**Last updated:** October 16, 2026

## 1. Purpose

Auto Confluence Documentation is a developer tool that helps authorized users generate and maintain project documentation using information from connected development services.

## 2. Information accessed

Depending on the permissions granted, the application may access Bitbucket repository content, Jira project information, Confluence pages, and account information needed to authorize and operate the integration.

## 3. How information is used

Information is used to generate, review, and update project documentation and to support the application's configured workflow.

## 4. Storage and processing

The application may process information locally and use configured services, including Amazon Bedrock, to generate documentation. OAuth credentials and tokens may be used to maintain authorized connections. Actual storage, retention, and deletion practices depend on the application's implementation and configuration.

## 5. Sharing

Information is processed by the services required to operate the application. It is not intentionally disclosed to unrelated third parties. The actual data flows and service providers should be documented according to the deployed configuration.

## 6. Security

Reasonable safeguards should be used to protect credentials, tokens, and project information. Users should not share credentials or grant permissions beyond those required.

## 7. Data deletion and contact

For questions about access, retention, or deletion of information, contact the person or organization operating this application.
